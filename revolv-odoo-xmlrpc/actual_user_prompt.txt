- status

On rerun, reconcile the ledger against the quantity currently read from Odoo.

A good state machine is:

- current == target
    → DONE / ALREADY_APPLIED
    → never apply the delta again

- current == baseline and no completed write is recorded
    → safe candidate to apply

- current is neither baseline nor target
    → CHECK / CONFLICT
    → do not write automatically

Make ledger writes atomic enough for this prototype:
- write temporary file
- replace final ledger file
